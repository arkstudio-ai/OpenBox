## 讲稿结构

讲稿只写会被念出的台词，按四段意图组织：

1. **钩子**：两秒内给反差、利益点或问题。
2. **展开**：按一至三个清楚讲点给事实、方法或演示。
3. **转折**：纠正常见误解，或把前文落到真实使用情境。
4. **收尾**：一句总结，再给自然的收藏、评论或行动邀请。

时长遵循用户已给或已委托的目标；未明确时按主流程自然确认或提出有依据的建议，
不固定成 45–60 秒。

## 标准骨架

每段按下列顺序组织，只有用户确认要保持的要素才逐字复用。人物身份参考不继承
原图的坐姿、背景、机位；不同场景的分镜分别写动作和运镜。以下占位内容来自
已确认方案，不是固定镜头或全片同背景的默认要求。无文字要求紧跟画面基底：

```text
全片一致的画面基底：<只写已确认需要保持的人物/商品等要素>
画面中不出现任何文字、字幕、标题、水印；字幕只能后期合成。
镜头设计：<本段确认的场景和运镜>。构图：<按分镜选择全景、中景或特写等景别>。
自然肢体动作：<本段脚本所需的动作>。
语气：自然、清晰、有感染力。
人物面对镜头开口说话。
口播台词：<本段逐字台词>
```

`口播台词：` 后只放台词，台词结束后换行；不要让画面描述变成模型要念的词。
prompt 任何位置都不写 `@`：模型会把它当字念出来（2026-09-14 线上 STT 在台词前
听到“艾博”“IPN”）。

## 七条军规

1. **台词单独成行，用 `口播台词：` 引出。** 冒号后逐字复制本段台词；边界
   模糊是说错话、说梦话和胡嘴的首要来源。不要用 `@` 标台词，模型会把它念成“艾特”。
2. **显式声明本段镜头设计。** 固定、跟随、环绕、推进、拉远等按用户目标和
   分镜选择，景别也按内容设计；只参考人物时不能默认复制原图机位和姿态。
3. **给一个克制的自然动作。** 手势随语气舒展，避免全程僵住或挥手。
4. **写语气，不写语速。** 精选集中语气出现率 80%，语速出现率 0%。
   语速词会和真实台词、显式 duration 互相竞争；节奏由讲稿和
   `plan_shots.py --rate` 决定。
5. **不要让生成模型烧字幕，但别指望它听话。** 用完整的否定描述——
   `画面中不出现任何文字、字幕、标题、水印；字幕只能后期合成`——紧跟画面基底
   写在靠前位置；只写 `无字幕` 是弱形式，lint 会提醒。这只能降低概率：
   2026-10-15 高德生产（crab-voucher）5 段 prompt 每段写了两遍“无字幕”，
   Seedance 2.0 仍把第 4、5 段的台词画进画面，且“限时”写成“随时”，音频念的
   是对的，STT 比对 97.8%/100% 全部放行。所以每个 take 的抽帧画面文字检查
   （SKILL.md 第 7 步）是必做项，检到即重拍；生成端文字写错无法修复，
   字幕只用 STT 实际词后期合成。
6. **场景与质感堆料要克制。** 长篇光影、材质、8K/棚拍修辞在问题组
   的出现率约为精选集两倍，并与换人、背景漂移相关。优先素材锚；
   文字场景控制在一两句，人物基底一个字不动。
7. **失败先准备原样重试一次。** 59 条真实重试链都是零改动重试，说明
   很多失败来自生成方差。任何重试仍是付费实拍，必须重新报段数、秒数、
   模型、分辨率和修改范围并获得确认；原样重试仍失败后才局部改 prompt。

## 素材 role 与编号

| role | 可用类型 | 用途 |
|---|---|---|
| `person` | image / video | 参考人物身份；是否沿用服装、姿态另行确认，不默认复制场景/机位 |
| `scene` | image | 按已确认范围参考环境布局或氛围，不自动锁定机位和光感 |
| `outfit` | image | 指定服装或分段换装 |
| `prop` | image | 指定手持、展示的产品或道具 |

这些是素材的创作用途，不是 `video_generate.input_assets[].role` 的枚举值。
先按 [material-plan.md](material-plan.md) 取得素材用途决定，实际传参按模型能力
使用 `reference_image`、`reference_video` 或首尾帧等角色。直接参考可以直接生成
新场景视频，不需要先生成图片；新首尾帧只在已确认的画面准备范围内制作。
Turbo 只接受明确的首尾帧，按
[minimax-turbo-frames.md](minimax-turbo-frames.md) 先完成整批画面准备；人物、服装、
场景源图若需合成新画面，先取得对应生图请求，不能直接作为通用参考传给 Turbo。

- 按用户标注使用 role，不猜素材用途。
- 图片与视频分别编号：第一个 video 是 `参考视频1`，第一个 image 是
  `参考图片1`，不是按混合输入的全局位置编号。
- 多人物要逐段写清谁出镜，例如“参考视频1的人物与参考图片2的人物并肩而坐”。
- 换装要组合指代，例如“参考视频1的人物穿着参考图片2的服装”；只在对应段
  更换服装编号。
- prompt 正文只写编号，不得出现 URL、`asset://`、内部 id 或文件路径。
- 零素材且用户未要求生图时，用文字写已确认主体和各段场景，只复用全片不变要素。
  Turbo 素材卡选择生成即为对应请求，先备齐并确认图片，再开始视频生成。
  不自动把生成视频中的截图用作新的通用人物参考。

## Turbo 首尾帧口播示例

以下示例特指已确认的同场景固定镜头口播，不能套到人物参考换景或走动运镜任务。

在结构化输入中绑定实际资产，prompt 中仅使用首帧、尾帧的画面语义。先确定同场景
各段一致的声线描述，再逐段复用；这只是提示，不代表模型支持声音参考或保证声线。
只传首帧时不描述不存在的尾帧；有尾帧时控制结尾姿态，不要求人物过早停止口播。

```text
全片一致的画面基底：保持首帧中同一人物、服装、室内背景、机位和光线。
画面中不出现任何文字、字幕、标题、水印；字幕只能后期合成。
固定镜头，保持首帧的半身中景构图。自然肢体动作：随讲解做克制手势，句末自然停顿。
语气：自然清晰；保持温和、清亮的成年女性声线。
人物面对镜头开口说话。
口播台词：今天分享两个整理桌面的小方法，先把每天用的东西放在手边。
```

```text
全片一致的画面基底：保持首帧中同一人物、服装、室内背景、机位和光线。
画面中不出现任何文字、字幕、标题、水印；字幕只能后期合成。
固定镜头，保持首帧的半身中景构图。自然肢体动作：轻轻示意桌面，逐渐落到尾帧的休息姿态。
语气：自然清晰；保持温和、清亮的成年女性声线。
人物面对镜头开口说话，完整说完台词后再进入句末停顿。
口播台词：再把不常用的物品收进抽屉，桌面清爽了，找东西也更方便。
```

这些示例中的声线、场景和景别按用户要求及实际首帧替换。每段完整 prompt 须符合实时长度限制，
并与确认的帧和台词一致。动作描述不应要求从已确认的起始画面突然换装、换景。

## 中文 few-shot 范例

这些范例已泛化；`<台词>` 必须换成本段完整原文。

**HOOK（坐姿定机位）**

```text
全片一致的画面基底：参考视频1的人物坐在参考图片1的简洁室内场景中，
人物、服装、背景与柔和室内光全片保持一致。
画面中不出现任何文字、字幕、标题、水印；字幕只能后期合成。
固定镜头中景，人物面对镜头，身体微微前倾，手势随语气自然舒展。
语气：热情有力。
人物面对镜头开口说话。
口播台词：还在为小户型显乱发愁？先别急着买收纳柜。
```

**BODY（数字或断言型讲点）**

```text
全片一致的画面基底：参考视频1的人物坐在参考图片1的简洁室内场景中，
人物、服装、背景与柔和室内光全片保持一致。

语气：自信、专业、自然。
人物面对镜头开口说话。
口播台词：先统一台面颜色，再把高频用品集中到一个区域。
```

**CLOSING（互动收尾）**

```text
全片一致的画面基底：参考视频1的人物坐在参考图片1的简洁室内场景中，
人物、服装、背景与柔和室内光全片保持一致。

语气：亲切、轻快。
```

**换装/换景（仅用户明确要求时）**

```text
固定镜头中景，参考视频1的人物穿着参考图片1的服装，背景为参考图片2的场景。
自然肢体动作：手势随语气舒展。语气：从容、专业。
```

**边走边说（街拍/探店）**

```text

人物边走边对镜头开口说话。

```

## 合规自审

提交前逐条看一遍：

- 不写医疗、解剖、诊断或疗效承诺等高风险词；
- 不仿品牌、名人或受保护 IP，不要求 logo 或水印；
- `person` 参考不是公众人物；真人素材走产品自身的身份授权流程；
- 无外部素材 URL、网盘、隧道或对外监听；
- 已写明画面中不出现任何文字、字幕、标题、水印，且位置在画面基底之后、台词之前；
  台词与 `口播台词：` 后内容一致；
- 素材编号存在，并且每项都列入本段结构化输入。
