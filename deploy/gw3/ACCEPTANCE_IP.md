# gw3 IP 入口浏览器验收流程（给浏览器 Agent 执行）

- 被测地址：`http://47.116.171.3`（无域名、无 HTTPS，浏览器地址栏会显示「不安全」，属预期）
- 产品：bossip（gw3 独立部署，2026-10-19 从 gw2 克隆，空库）
- 登录方式：HTTP 下浏览器不提供 SSO 需要的 `crypto.subtle`，点「单点登录（SSO）」后页面会**自动退回本地账号密码表单**（预期行为，不是故障）。用本地「注册」建账号（用户名 + 邮箱 + 密码，不需要短信），之后用账号密码登录。有 HTTPS 域名后才会走 Logto。
- 执行人：浏览器 Agent；每完成一组把结果写进文末「验收报告」模板。

## 0. 执行规则（必须遵守）

1. **不付款**：任何支付宝/微信付款页面、二维码出现就停，记录截图，不扫码不付款。
2. **不点「调整订阅」「充值积分」以外的管理写操作**；`H 组（云电脑）` 会真实购买云电脑，只有测试负责人明确说「执行 H 组」才做。
3. 不在「授权中心」里真实授权抖音/美团等第三方账号（看页面即可）。
4. 不改「定价」页任何数值。
5. 每个用例记录：结果（通过/不通过/阻塞/跳过）、实际现象、截图文件名；不通过时打开开发者工具，记录 Console 红色报错和 Network 里 4xx/5xx 请求（URL + 状态码 + 响应前 200 字）。
6. 遇到「出错了」页面或白屏，先刷新一次再判断；刷新后好了也要记录。
7. 视频生成会消耗较多积分，只在 D2 做一条；图片只在 D1 做一张。
8. 时间以页面显示为准，所有用例在同一个浏览器（桌面版 Chrome，窗口 ≥ 1280 宽）完成，移动端只在 I1 用开发者工具模拟。
