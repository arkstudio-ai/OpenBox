# 超管订阅与积分管理

网页和原生移动端入口：**超管 → 订阅管理**。搜索用户名、邮箱或空间名称，打开目标空间详情。

积分和订阅属于空间。一个用户拥有多个空间时，先核对空间，再提交操作；仅全局 `admin` 可操作，空间管理员没有这项权限。

- **充值积分**：增加可用积分，支持 6 位小数，单次大于 0 且不超过 1,000,000。免费账号也可获得人工积分；这项操作不更改套餐、不产生支付订单。
- **开通 / 续期**：选择专业版或旗舰版，以及 1 个月或 1 年。接在现有订阅（包括排队续期）之后，没有有效订阅时立即生效。包含套餐周期积分和对应权益，按原有订阅规则发放。
- **调整订阅**：在订阅历史中调整所选时段的套餐和到期时间。已有订单和已发积分保留，新到期时间不能与其他时段重叠。套餐切换沿用现有按套餐和周期去重的积分发放规则。
- **终止订阅**：立即结束所选时段，保留其他排队续期、订单记录和已发积分，不触发支付退款。没有其他当前有效时段时回到免费套餐。

所有操作必须填写原因并确认目标账号和空间。已删除空间或停用账号不可写入。详情页的“积分账本”和“管理操作记录”显示变更结果、操作人及原因。

遇到网络超时或服务器错误，界面会保留原操作。使用“确认并重试原操作”，服务端按原请求编号核对，避免重复到账。网页同一标签页刷新、移动端关闭重开表单也会恢复待确认操作。修改过的订阅使用旧页面提交时会被拒绝，刷新后再核对。

## 实现与运维

写接口位于 `/api/admin/billing/workspaces/{workspace_id}`，包括 `POST /credits`、`POST /subscriptions`、`PATCH /subscriptions/{id}` 和 `POST /subscriptions/{id}/cancel`。在同一数据库事务中持有空间积分账户锁，更新账本或订阅并保存审计回执；每次写入重新核对当前账号的超管权限。

业务迁移 `f8b3d6a1c092` 为订阅增加独立身份和终止时间。已有付费时段继续使用订单号作为身份，人工开通不创建虚假订单。生产升级时先停旧后端写入，再迁移、启动新版本。轨迹库结构不变。

回退旧后端前必须先确认迁移兼容并降回 `d0a2c4e6f8b1`。一旦已有人工订阅或终止记录，降级会拒绝执行；此时应修复新版本，不能为了回退覆盖业务数据库。

2026-09-29 按用户授权，将线上唯一有效用户名 `e` 的账号提升为全局 `admin`。服务器维护记录位于 `/opt/openbox/operator-actions/20260929-enable-admin-e.json`。现有令牌保留旧角色，该账号需退出后重新登录。此次权限变更没有充值积分或修改订阅。
