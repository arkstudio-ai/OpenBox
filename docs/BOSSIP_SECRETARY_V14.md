| 当前回答优先 | 直接查询及工具结果回传期间不插入旧任务提醒；一次答复用完的回执不混入下个问题 | 工具调用、输出完成和语音回复状态 |

没有新增中文口令匹配或确认词表。模型解释上下文，服务端验证结构化选择、权限、过期状态和实际执行结果。

## 对文档示例的校准

- 示例价格不是当前计费配置。实现读取真实积分，不改价、不宣称快速档一定最便宜。
- 支持参考图片不等于必须上传；标准/极致档也不能保证兼容任意素材。
- 登录授权、内容发布、私信代回、投流预算与定时汇报是不同操作范围。
- 二维码、验证码发送、投放成功、持续监控和文件导出都要有真实执行依据。
- 换配音、重新生成或云合成可能收费，不能笼统承诺免费或一分钟完成。
- 视频号目前没有已注册的自动登录探测器；可由执行任务查看真实浏览器页面，不宣称已增加完整平台 API 集成。
- 充值付款与绑卡由用户在平台完成。未知经营数据保留为未取得，不报成零或套用文档业绩例子。

## 本地定向验收

环境：本地 QA 账号，Web 3001 / API 8081；任务模型 Gemini 3.8 Flash High，语音 Audio 3.1，
视频快速档实际绑定 MiniMax-H3-Max-Turbo。测试配置移除了 GPT 路由。
通过浏览器输入和真实语音连接操作；语音输入使用合成中文 PCM 注入麦克风轨道，因此覆盖模型、工具与页面链路，
不包含物理麦克风噪声、回声或移动端声学测试。

本轮只跑受影响的定向测试，不运行全套测试，不重复整段付费视频制作。
原始本地证据保存在 `.local-dev/voice-guide-v14-20261013/`，不提交个人 QA 记录或凭证。

### 浏览器发现并修复的问题

1. 已在语音里选好快速档，新任务仍重复问档次：任务草稿早于卡片决定，新增服务端确认数据消除歧义。
2. 讲稿卡只有“是否符合要求”，看不到稿件：技能要求把全文与时长放进问题本身，供页面与语音共同读取。
3. Audio 把无授权记录误说成未连接：语音工具改为返回实际记录与明确的未知结论，避免把空平台目录当作检测结果。
4. 多任务并存时用旧任务 ID 提交新任务的答案：增加对话名称一致性校验、拒绝不一致的提交；连续错误重试有上限。
5. 查询尚未回传时旧提醒插入，导致答非所问：等待当前工具输出与回复结束，再交付排队提醒；旧确认回执不复用于下次查询。

已通过的本地浏览器链路：未选档时只出现准备卡；语音选择快速档后仅创建一个任务；Gemini 执行并加载
`video-production`，内部绑定 MiniMax-H3-Max-Turbo / 768p；确认卡显示完整 5 秒讲稿，未重复问档次、字幕和音乐。
语音确认后讲稿交付；审计未发现本轮新增视频生成、发布或定时任务。素材追问中实际回答可用纯文字描述或资源库图片，
没有擅自替用户选择或生成图片。
最终使用相同账号问题复测，Audio 明确回答“当前登录状态未核验，无法判断现在是否已经连接上”，
说明本次只读取历史信息，未自动登录。口头回答长度仍有波动，特别是复杂旧任务提醒；
本次没有用固定播报模板或截断文本来伪造“两句话”效果。

定向检查分批进行，存在重叠，不累计为一个虚高总数：工作流/卡片/路由/Provider 相关 123 项通过；
播报顺序和工具交接相关 50 项通过；最后修改的回执消费场景单独复测通过；WebSocket 19 项通过。
此外，秘书事实与权限测试 5 项、助手命令测试 9 项均通过。

首次介绍、跨工作空间权限、凭证不泄漏、未知状态、真实价格、档次变化与幂等交接均有定向测试。
商户真实扫码登录、公开发布、充值投流与有真实经营数据的报表导出尚未进行线上验收；新增技能不能替代这些实测。
