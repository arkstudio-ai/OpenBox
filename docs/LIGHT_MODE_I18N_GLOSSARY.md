# Light 模式三语术语表（中 / 英 / 越）

> 2026-11-08 起草，配合 `LIGHT_MODE_I18N_PLAN.md` §4。越南语为机器初翻，待越南语母语审校定稿；审校改动后以本表为准回写文案文件。
>
> 规则：
> - 品牌名 `bossip` 三语都保留原样，不翻。
> - 平台名用英文：Douyin、TikTok、Meituan、Dianping、Xiaohongshu、WeChat。
> - 越南语允许夹英文专有名词（PDF、MB、AI、Light、Pro、OK），不强行造词。
> - 中文版术语不变；英文版复用现有 `en-US` 文案；越南语以英文为源、中文校对语气（对象是小店老板，口语、短句，用「bạn」称呼用户，助理自称「tôi」）。
