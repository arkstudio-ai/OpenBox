# 长期记忆、知识库、个人助理与语音通话：分支更新说明（2026-10-08）

`codex/long-term-memory-plan` 合入 `main` 的说明，覆盖 2026-10-01 至 10-08 的 264 个提交（不含合并提交）。合入时 `main` 在 `bbb8e4b1`（Seedance 2.5 / ultra 档），分支已包含 main 的全部提交，没有冲突。

**合入 main 不等于上线。** 生产环境运行 main，但发布仍按 [DEPLOY.md](DEPLOY.md) 手动进行。发布前请先读第二节：个人助理和新版左栏没有开关，部署后所有用户都能看到；长期记忆和语音通话各自有开关，默认关闭。

规模：后端 635 个文件（+90k 行，含测试）；网页 295 个文件；手机端 128 个文件。

## 一、更新内容

### 1. 长期记忆

- **抽取与核验**：从对话里自动抽取，只保存用户原话能证明的事实。每条先核验再写入，记下来源消息，可以追溯。
- **召回**：
  - 按个人和项目两种范围召回；
  - 由 JEV 判断这一轮要不要查记忆；
  - 向量检索后再精排，阈值可调；
  - 读取时按当前权限重新核验。
- **遗忘与去重**：
  - 用户删掉的记忆不会再被学回来；
  - 同一事实的多条副本自动合并；
  - 一次性安排带有效期，过期后不再出现；
  - 密码、证件号、银行卡号、联系方式等敏感信息不会被记住。
- **调试**：调试视图和回放，可以看到每一阶段的耗时和候选。
- **召回提速**：provider 连接池、查询向量缓存、批量读取权限；认领输入后立刻开始召回。实测每轮约省 0.5–0.75 秒。
- **个人助理的记忆**：从个人助理对话里学到的个人记忆，可以在个人范围内跨项目使用。

详见 [LONG_TERM_MEMORY_PLAN.md](LONG_TERM_MEMORY_PLAN.md)、[LONG_TERM_MEMORY_IMPLEMENTATION.md](LONG_TERM_MEMORY_IMPLEMENTATION.md)。

### 2. 知识库

- **知识库页面**：一个面向普通用户的页面，包括：
  - 记忆按时间分组，每条标注来源（从对话里学到 / 你确认过的）；
  - 后台自动整理的主题页（Wiki 编译器）；
  - 上传的文档：切块后可引用，重复上传可识别；
  - 页面上只保留阅读、搜索、添加和简单编辑，核验、组织、发布都由后台自动完成。
- **手机端**：同样有知识库（记忆、主题、文件），整体改得更简洁。

详见 [CONSUMER_KNOWLEDGE_IMPLEMENTATION.md](CONSUMER_KNOWLEDGE_IMPLEMENTATION.md)、[WIKI_PLATFORM_PLAN.md](WIKI_PLATFORM_PLAN.md)、[WIKI_READER_IMPLEMENTATION.md](WIKI_READER_IMPLEMENTATION.md)。

### 3. 个人助理

一段长期对话里的私人秘书。用户交代事情，它派到对应项目的对话里执行（需要时用云桌面），然后跟进进度、用白话汇报结果。

- **交代与执行**：
  - 等用户回复的问题集中成卡片，可以由助理代答；
  - 任务可以暂停、继续、取消；
  - 支持定时任务和每日简报；
  - 维护每个用户自己的项目档案；
  - 新建项目、删除等操作要先经确认卡片；
  - 也能接管用户已有的项目对话。
- **一段对话保持流畅**：滚动摘要用用户的语言写，不含敏感细节；每轮有时间和调用次数上限；同时进行的任务排队公平。
- **权限与隐私**：只按当前权限读取，不再追溯来源链（V2 设计）；汇报内容不能借工具注入指令；界面上不显示任何 ID。私有浏览器和私有执行环境已移除，委托的工作统一走云桌面。
- **个性化**：
  - 可以设置名字、对用户的称呼、语气、回答长短、是否用表情、补充说明、通话习惯；
  - 网页、手机、文字回复和电话前台共用同一份设置，改了以后所有打开的页面立刻跟着变；
  - 相处方式卡：说话偏好来自记忆和反复出现的点踩原因；
  - 点踩可以选原因；
  - 回答下方显示“参考了 N 条记忆”。
- **初次见面**：
  - 由 App 来问（不交给模型），最多四个问题：称呼、名字、回答长短、行业，每个都能跳过；
  - 每个字段单独记一笔“决定”，这样能分清设置过、跳过和还没问；
  - 对长短、语气、表情、电话详略的反馈，在助理对话里说的会直接改设置。

详见 [PERSONAL_ASSISTANT_DESIGN_V2.md](PERSONAL_ASSISTANT_DESIGN_V2.md)。V1 的设计和性能记录见 [PERSONAL_ASSISTANT_DESIGN.md](PERSONAL_ASSISTANT_DESIGN.md)、[PERSONAL_ASSISTANT_PERFORMANCE.md](PERSONAL_ASSISTANT_PERFORMANCE.md)。

### 4. 实时语音通话（个人助理的电话前台）

- **在哪里打**：网页是悬浮通话窗；手机是通话页，外加一条不遮挡页面的顶部通话条。
- **模型与接通**：实时语音模型默认 `qwen3.8-omni-flash-realtime`。接通后先放回铃音，问候准备好了就开口；走代理还是直连同时尝试，用先通的那条。
- **怎么回答**：
  - 前台按用户的设置和相处方式说话；
  - 涉及工作进展的问题交给助理处理，并用助理的模型；
  - 交出去的事不会被说成已完成，说过头了会当场更正；
  - 用户的答复一定会送到助理。
- **汇报**：通话中可以汇报任务结果，多条合并说。
- **记忆**：闲聊里说到的长期信息会安静地交给助理记下；第一通电话会问一次怎么称呼。
- **设置与计费**：音色可选；开场是否提上次、是否主动汇报、详略都可以设置；通话按积分计费。

详见 [VOICE_CALL_SPEC.md](VOICE_CALL_SPEC.md)、[VOICE_CALL_BACKEND.md](VOICE_CALL_BACKEND.md)、[VOICE_CALL_WEB.md](VOICE_CALL_WEB.md)、[VOICE_CALL_MOBILE.md](VOICE_CALL_MOBILE.md)。

### 5. 网页与手机端

- **网页左栏**分为上下两区：
  - 上区：品牌、工作空间、个人助理卡片、功能入口图标格（云桌面、消息中心、知识库、定时任务 / 资源中心、技能中心、授权中心、订购）；
  - 下区：新对话、新建项目、搜索、项目树。
  - 搜索能搜对话标题和正文。
  - 定时任务不再列在左栏。
- **手机端**：
  - 左栏改成同样的两区结构；
  - 个人助理改成白话界面；
  - 新增知识库和语音通话；
  - 标题栏、授权中心、定时任务卡片等页面做了整理。
- 中英文案网页与手机逐字一致（`mobile/scripts/check_locales.sh`）。

### 6. 其他

- 消息中心：可以只列出某几类通知，并给出这几类自己的未读数。
- 轨迹库：记录每条轨迹的可见范围（`t0005`）。
- LLM 工具参数：把“多种对象之一”声明成一个对象，避免 qwen 把对象参数写成 JSON 文本。这正是确认过的定时任务连续创建失败的原因。
- 云桌面执行服务（`container/`）：执行身份隔离、文件 worker、资源门禁、存储迁移；`action_server` 支持资源控制命令的固定与重放。
- `demos/realtime-voice/`：实时语音的独立演示和计价脚本。

| 功能 | 开关 | 默认 | 说明 |

### 外部服务与密钥（只写变量名）

- **Qdrant**：记忆的向量索引，用 `MEMORY_QDRANT_URL` 配置，可选 `QDRANT_API_KEY`。本地用 `docker-compose.memory.yml`（`qdrant/qdrant:v1.19.0`）。
- **阿里云百炼 / DashScope**：用于向量、精排、实时语音和通话交接摘要。密钥读 `DASHSCOPE_API_KEY`；记忆部分也接受 `MEMORY_BAILIAN_API_KEY` 或 `BAILIAN_KEY`。
- **TypeSafe JEV**：用于记忆路由和通话中的判断，读 `TYPESAFE_API_KEY` 或 `JEV_KEY`。
