# 移动端引导方案（2026-09-15 草案）

范围：BossIP 移动端（Flutter）。**本版只做移动端**，Web 另行设计，不共用组件与文案。
现状：移动端与 Web 均无任何引导；没有首启标记、没有蒙层，各页面只有一句空态文案。用户登录后直接落在空对话页（问候语 + 下一步建议 + 输入框 + 抽屉侧栏）。

已拍板（2026-09-15）：
1. 触发口径按**账号**：新账号首次登录一定触发；同一账号换机不重复（标记存服务端）。
2. 移动端独立设计、独立实现，本版不做 Web。
3. 三层都要：首启介绍 banner、登录后介绍、蒙层（coach mark）引导。

## 1. 三层引导与存储

| 层 | 时机 | 存储 | 说明 |
|---|---|---|---|
| L1 首启 banner | 安装后首次打开，登录之前 | 本机 `shared_preferences`（`bossip:intro_seen`） | 登录前没有身份，只能按设备。3 屏可滑动，右上角"跳过"，最后一屏"登录 / 注册" |
| L2 登录后介绍 | 账号首次进入工作空间（`WorkspaceBootstrap` 完成后、空对话页出现前） | 服务端偏好 `onboarding.welcome_seen` | 1 屏欢迎 sheet + 空对话页 3 张示例任务卡。新账号注册即登录，天然触发 |
| L3 蒙层引导 | 各界面首次出现时 | 服务端偏好 `onboarding.marks[<key>]` | 半透明遮罩 + 高亮锚点 + 气泡，"下一个 / 知道了 / 全部跳过" |

服务端：`PreferencesUpdate` 新增顶层字段 `onboarding: dict | None`，仓储层对该字段做**键级合并**（现有 `extra` 是整体覆盖，外观设置正在用它，不能混用）。
`GET /api/auth/me/preferences` 返回 `onboarding`；App 在 bootstrap 时读一次，本地缓存，写入时先写本地再异步 PUT（失败不阻塞 UI，下次启动以服务端为准）。
"重看引导"入口：设置 → 账号 → 「重新查看新手引导」，清空 `onboarding` 后回到空对话页重放 L2 + L3。

## 2. 文案与门禁

移动端 locale 目录 `assets/locales/` 是 Web 的逐字节镜像，`scripts/check_locales.sh` 会 `diff -qr`，不能加文件。
引导文案放**独立目录** `mobile/assets/locales-mobile/{zh-CN,en-US}/onboarding.json`，`i18n.dart` 追加一个只从该目录加载的 `onboarding` 命名空间；门禁脚本不改。
文案口径沿用落地页人设：面向老板 / 线下店，动词开头、不出现"沙箱""token""agent loop"这类词；界面里已有的名词（云电脑、技能、授权中心、积分）第一次出现时用一句话解释。

## 3. 引导点清单

键名即 `onboarding.marks` 的 key。"账号首次"= 该账号第一次到达该界面；"空间首次"仅用于云电脑相关（云电脑是工作空间资源），但**标记仍按账号存**，键里带 `workspace_id`。

### M1（P0：首次会话必须走通）

| 键 | 触发 | 形式 | 内容要点 |
|---|---|---|---|
| L1 `intro` | 安装后首次打开 | 3 屏 banner | ① 把营销、发布、经营琐事交给随时在线的 AI 搭档；② 一句话下达任务，它在云电脑上替你操作抖音 / 来客等平台；③ 结果、审阅与提醒都会回到手机上。末屏：登录 / 注册 |
| L2 `welcome` | 账号首次进入空对话页 | 欢迎 sheet（1 屏） | 你好 {{name}}，先从一件事开始；三步：说需求 → 它执行并在需要时问你 → 你审阅结果。按钮"开始" |
| L2 `starter_cards` | 同上，sheet 关闭后 | 空对话页 3 张示例任务卡 | 「做一条 30 秒的门店短视频」「把上周的经营数据整理成一页」「写一段周末活动的推广文案」。点击填入输入框并发送；首次发送后卡片消失（`starter_cards` 置已看） |
| L3 `composer` | 首次聚焦输入框 | 气泡 | `/` 添加上下文，`@` 引用资源中心的文件，右侧「更多」可上传与截图 |
| L3 `drawer` | 首次打开侧栏 | 蒙层，7 步 | 项目与对话（对话按项目归类）→ 资源中心（对话产出与上传的文件）→ 技能中心（给它装能力）→ 授权中心（绑定抖音等账号它才能替你发）→ 消息中心（任务结果与官方通知）→ 定时任务（让它定期做）→ 订购（积分与套餐） |
| L3 `panel_entry` | 首次出现「打开工作面板」按钮的会话 | 气泡 | 这里能看到它的云电脑、浏览器、文件和待审阅的改动 |
| L3 `panel_tabs` | 首次打开工作面板 | 蒙层，逐标签 | 云桌面（它替你操作网页的那台电脑）、浏览器、文件、审阅、终端。Free 用户在订阅提示上方加一句"为什么需要云电脑" |
| L3 `notify_prepermission` | 首次即将请求系统通知权限（当前 `PushController` 首登即请求，需改为在 `welcome` 关闭后） | 前置说明页 | 只在你离开 App 时提醒任务结果和待确认事项；前台不弹。按钮"开启提醒 / 稍后"。点开启才触发系统弹窗 |
| L3 `desktop_takeover` | 接管卡片首次出现 | 卡片内高亮 3 步 | 打开云桌面 → 在里面完成验证 → 回来点「我已完成，继续」。现有文案保留，只加首次高亮 |
| L3 `auth_center` | 首次进入授权中心 | 顶部说明卡 | 绑定抖音账号后它才能替你发布视频与查看数据；扫码 → 在手机抖音确认 → 回到这里看到已授权 |

### M2（P1：功能页首次进入与聊天卡片）

| 键 | 触发 | 形式 | 内容要点 |
|---|---|---|---|
| `inbox` | 首次进入消息中心 | 顶部说明卡 | 三类：会话结果、系统提醒、官方通知；点结果直达对应对话 |
| `cron_empty` | 定时任务空态 | 空态改造 | 一句话创建示例 + 按钮「用聊天创建」 |
| `skills_empty` | 技能中心空态 | 空态改造 | 技能是给它装的能力；两个去向：商店、聊天创建 |
| `resources_empty` | 资源中心空态 | 空态改造 | 资源从哪来：对话产出、你上传的 |
| `credits` | 首次看到积分余额（侧栏用户行） | 气泡 | 积分是什么、视频 / 图片 / 对话各自怎么扣，链到用量页 |
| `card_question` / `card_plan` / `card_permission` / `card_video_review` | 对应卡片首次出现 | 卡片顶部一行说明 + 「知道了」 | 提问卡：它在等你回答，不答会一直暂停；计划卡：先确认再执行；权限卡：只在这次或始终允许；视频审阅卡：看片、改词、重生成 |

### P2（后放）与不做

- 设置各页只做字段级 tooltip；工作空间切换与团队邀请在出现第二个空间时提示。
- 不做：落地页（本身是营销页）、登录 / 注册（SSO 一键）、超管系统与舰队（内部人员）。

## 4. 技术设计

- `lib/features/onboarding/`：
  - `state/onboarding_controller.dart`（Riverpod）：`seen: Set<String>`，`markSeen(key)`，`reset()`；bootstrap 时从偏好加载，失败回退本地缓存。
  - `widgets/intro_banner_page.dart`（L1，路由 `/intro`，在 `SsoGate` 之前）。
  - `widgets/welcome_sheet.dart`、`widgets/starter_cards.dart`（L2）。
  - `widgets/coach_mark.dart`：`CoachMarkAnchor(key)` 包裹目标控件，`CoachMarkSequence` 用 `Overlay` 画遮罩与气泡，支持多步、"全部跳过"、返回键关闭。不引第三方包，颜色走 `BossipTokens`，明暗两套。
  - `widgets/first_seen_hint.dart`：卡片首次说明行（M2）。
- 触发统一走 `OnboardingController.shouldShow(key)`，界面在 `postFrameCallback` 里请求，同一时刻只允许一个引导在屏（队列），避免与提问卡、订阅提示、开通进度弹窗叠加。
- 通知权限顺序：`welcome` 关闭 → `notify_prepermission` → 系统弹窗。`PushController` 现有的首登请求改为等待引导队列空闲。
- 后端：`PreferencesUpdate.onboarding: dict | None`，仓储 `upsert` 对 `onboarding` 做键级合并；`reset` 用 `{"onboarding": {}}` 显式清空的语义单独处理（传空对象 = 清空）。
- 文案：`assets/locales-mobile/*/onboarding.json`，`i18n.dart` 加载路径按命名空间区分；`pubspec.yaml` 追加资产目录。
- 门禁：Dart 文件 ≤ 800 行；`check_locales.sh` 不改；新增单测覆盖 controller 的合并 / 重放与 coach mark 的队列互斥。

## 5. 验收

1. 新注册账号首次登录：L1（若首装）→ L2 → 侧栏与输入框的 L3 全部出现且各只一次。
2. 同账号在第二台手机登录：L1 出现（设备级），L2 与 L3 不再出现（服务端标记）。
3. 任一引导可跳过；系统返回键关闭当前引导不影响后续。
4. 设置里「重新查看新手引导」后，L2 + L3 完整重放。
5. 引导不与提问卡、订阅提示、开通进度弹窗同时出现。
6. 明暗主题、中英文、四档字号下气泡不遮住锚点、不溢出屏幕。
7. 通知权限系统弹窗只在前置说明页点「开启提醒」后出现。
