# BossIP 1.0.34（45）更新简介

本次基于 main 发布至 https://ai.bossipai.com.cn/ ，安卓包沿用 BossIP 正式发布证书。更新范围从本群上次正式版 1.0.33（44，2026-10-10）起计算。

## 语音助手

- 默认使用 Audio 3.1，按照上下文理解需求、选择与确认，减少固定口令和机械播报；已明确选择的内容不再重复询问。
- 移除固定通话时长限制，增加静默保活、断线恢复及有边界的超时处理；避免在结果未明时重复执行操作。
- 结合已有项目和会话安排任务，必要时自然询问创建新项目或会话；新会话先说明可选任务 AI，再按用户决定执行。
- 优化 v14 秘书对话指引、任务进展播报和跨任务确认，先回答当前问题，减少旧任务结果插话及错误确认。

## 视频与图片制作

- 视频需求先确认制作形式，再自然说明视频模型或快速、标准、极致档的区别。
- 口播任务加载视频制作技能，保留已确认的讲稿、素材、时长、首尾帧及制作要求；语音可接管选择和确认卡片。
- 支持从资源库选图、上传素材、解释实际图片，以及经用户确认后用参考图生成新首尾帧。
- 设置中新增 Default / RunningHub 图片来源，RunningHub 的具体图片模型由系统统一配置。
- 支持 MiniMax-H3-Max-Turbo；Wan 3.0 接入阿里云原生通道。费用、生成及交付仍按任务流程确认。

## 安卓同步与问题修复

- 补齐问题卡的资源库选择、手机相册/文件上传、图片预览和素材草稿同步；素材可随回答提交，并供语音助手接续处理。
- 问题卡展示模型和选项说明；上传过程中避免提前提交，选项与素材可一并确认。
- 已登录启动进入应用，区分登录和注册；同步无通话倒计时、图片来源设置、任务卡继续处理等主线改动。
- 修复任务等待确认和取消卡住、云电脑截图后点击失效及部分文件操作状态异常。

## 管理与运营

- 管理后台新增轨迹简明视图、按用户/对话轮查看步骤与积分，以及失败提醒。
- 新增定价管理，展示成本、售价与毛利；更新视频和剪辑计费规则。
- 增加经营助手的授权状态查询与执行指引；具体平台操作仍以真实登录状态、可用工具和用户授权为准。

## 安装

解压 7z 后安装其中的 APK。已安装上一版正式签名包的手机可直接覆盖升级。请保留原应用及数据；若系统提示签名不一致，先确认旧包来源，不要贸然卸载。

本次按要求未运行自动化测试、模拟器或业务场景复测，仅进行发布构建、签名、压缩包和服务部署状态核验。安卓新增素材流程尚未进行真机实测。
