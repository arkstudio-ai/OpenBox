# BossIP 1.0.35（46）更新简介

本次基于 main 发布至 https://ai.bossipai.com.cn/ ，安卓沿用 BossIP 正式发布证书。更新范围从本群上次正式版 1.0.34（45，2026-10-13）起计算。

## PC 网页悬浮助手

- 页面上新增助手形象入口，可拖动调整位置，随时展开聊天窗口或发起语音通话。
- 悬浮窗口支持聊天、快捷设置和回到完整助手页面；收起窗口后仍可保持通话。
- 快捷设置可调整语音模型、音色、沟通方式与任务播报偏好。
- 支持预设形象和上传自定义形象，保存到账号后同步使用。
- 通话窗口和收起后的助手入口均支持静音 / 取消静音，明确显示当前麦克风状态；静音期间仍可听到助手回复。

上述悬浮窗口功能面向 PC 网页；本次安卓包未加入移动端悬浮窗口。

## 聊天与安卓界面

- 收紧空输入框和底部留白，让悬浮聊天及任务会话更紧凑。
- 将“内容由 AI 生成，请注意核实”与服务说明放入输入框底部提示行，适配移动端换行及安全区域。
- 去除文字输入时突兀的矩形焦点边框，保留整体输入框的自然交互样式。
- 完整助手页面与悬浮窗口共享消息订阅，减少重复消息更新及多余请求。
- 加强账号、空间切换时的状态处理，避免旧请求混入当前界面。

## 接口与管理后台

- 开放接口新增单次请求积分上限 max_credits，在镜头生成与合成提交前核对额度，超限时不提交付费操作；不包含文本调用费用。
- 管理后台的轨迹产物增加“打开原文件”，支持在权限校验后直接访问实际图片、视频等产物。
