# BossIP 1.0.36（47）更新说明

对比产品交流群上次发布的 1.0.35（46，2026-10-14）。安卓客户端连接正式环境 `https://ai.bossipai.com.cn`，使用与上一版相同的正式签名。

## 语音与个人助理

- 语音助手保持独立对话，按需交办任务；减少每句话都转交个人助理造成的等待。
- 同步手动创建的会话、任务进展、已回答卡片和近期素材，让语音与文字对同一件事保持一致。
- 手动回答卡片后，语音及时更新状态；点击其他任务的卡片不会误打断当前语音。
- 有旧确认卡时，也可以表达新需求或修改方案。例如从无图生成改成使用刚上传的门店图片，保留新要求与附件，避免反复确认旧脚本。
- 使用当前设置的助手名字和用户称呼；用户未设置称呼时默认“老板”，避免沿用历史占位符。

## 素材与视频任务

- 普通会话、个人助理和语音共享可访问的附件；支持按完整文件名及描述查找素材。
- 新上传图片支持 AI 自动生成描述，也可手动修改，便于后续语音定位。识别失败会显示状态，不会把文件名当成识别结果。
- 修复媒体工具参数过大、部分文件名显示不全，以及模型流中断被误认为完成的问题。
- 改进任务受理与超时回执：区分已经排队、等待确认、执行中与回复超时，避免同一请求重复建任务。单轮保护额度仍保留。
- 优化图片批次与中断恢复，视频制作先明确参考素材用途、再确认方案及费用。

## 会员与云电脑

- 统一命令执行、电脑操作和浏览器工具的会员资格判断；剩余积分不代表会员仍有效。
- 会员到期时明确提示开通或续费，保留原输入和参考附件，停止无效重试。
- 续费或运营补开后，自动恢复原有云电脑的使用资格和激活流程。

## 安卓

- 系统返回键优先关闭弹层、返回上级或打开导航，避免直接退出应用。
- 从后台返回及重新打开时恢复上次聊天位置，并按账号隔离保存状态。
- 同步任务状态、用户称呼、预算与会员错误提示，改善等待和失败时的说明。

## 安装与验证

解压 7z 后安装 APK。上一版正式签名可覆盖升级，保留聊天和登录数据。遇到签名不一致时先核对旧安装包来源，不要直接卸载。

本次只运行与改动直接相关的定向测试及必要回归。发布证据另行记录；本说明不代表未经执行的真机、模型生成或网络稳定性验证。
