## 带上的改动

- **助理页就是通话页**（PR #131，VOICE_SEAM_PLAN §13）：不再有独立的 VoiceCallPage / 牌组 / 会话卡。通话住在状态栏下 44pt 的通话条里，往下拉出半屏半透明的逐字稿抽屉（助理名在左、"我"在右、盯现场时显示"帮手"），抽屉里有控制、花费和结束小结，上滑收起。电话按钮原地拨号；`/app/voice` 重定向到助理页。"盯现场"开关搬到当前这件活的任务卡上（`taskCardExtraProvider`）；`VoiceLine.room` 在收到时就标记房间内说的话。
- **1.0.47 带的 I 轮**（因 1.0.47 未合 main，这是它第一次随 main 发）：打电话时当前这件活的任务单；"盯现场"开关，打开后你说的话直接给这件活、它的回复直接播，活做完或被停下服务端自动关掉（协议新增客户端→服务端 `room {task_id|null}`）；这件活的提问/授权并到任务单，别的活的仍单独；文案 `voice.transcript.watch*` 与 Web 逐字节镜像。
- PR #129（通话开场/交办话术）和 PR #132（视频房间确认计划后继续出片）只改服务端，App 无代码变化，随配套服务端生效。

## 验收要点（未做真机）

1. 进助理页按电话按钮：不跳页，状态栏下出现通话条，页面仍是助理页；往下拉出半屏逐字稿抽屉，上滑收起。
2. 抽屉里助理的话在左、我的话在右；打开某件活的"盯现场"后，回复显示为"帮手"。
3. 通话中交代一件活：这件活的任务卡上有"盯现场"开关；活做完后开关自动变回关。
4. 旧入口 `/app/voice`（深链/通知）打开后落在助理页，不白屏。
5. 结束通话后抽屉里有花费和结束小结。
