## 1. 工作流（可并行的几条线）

五条线：A 桌面、B 底座与计费、C 技能、D 推广前后置、E 产品表达。

| 编号 | 事项 | 内容 | 依赖 | 粗估 |
|---|---|---|---|---|
| A1 | 每桌面执行通道 | 每台 ECD 自己的 action server 回连隧道（倾向 bossip 的 frpc 方案或反向 SSH 端口池），provider 按用户路由，`routes_per_user=True`，云桌面 tab 播用户自己的桌面 | 无 | 2–3 周 |
| A2 | 包月开通 | CreateDesktops 传 period / auto_renew；到期语义改为「不续则到期释放」；鬼桌面清理对包月改标记不硬删 | A1 | 0.5 周 |

## 2. 里程碑建议（顺序，不给日期）

| 里程碑 | 含义 | 包含 | 验收 |
|---|---|---|---|
| **M-A 打通** | 一人一台桌面真正可用，账能对上 | B1、A1、A2、B2、B3 | 新用户注册 → 拿到自己的桌面 → agent 在上面跑；shadow 账本一周内与网关日志对得上 |
| **M-B 可收费** | 能真实付款开通并按月续，出片质量与首屏表达跟上 | A3（预热）、B4、A5 v0、C5、E1、E2 | 真实付款 → 开通 → 使用 → 到期 → 续费全链路；平台账号能登记与探活；口播成片规则对照 bossip 逐条通过；landing 与空白对话引导换成业务口径 |
| **M-C 可运营** | 运营不用进数据库 | B5、A4、C1–C4、B6 | 后台能调账、看舰队告警、发布第一方技能；移动端同构 |
| **M-D 可推广** | 拉新与保全 | D1、D2、D3 | 试用池与拉新跑通；桌面快照可恢复 |

关键路径：B1 → A1 → A2 → B4，其余可并行。**B1 和 A1 应第一周就开工**，一个是所有表的边界，
一个是所有桌面工作的前提。

4. 预热水位与包月采购审批人（A3 涉及真钱）。
5. EC2 生产栈的去留时间点。
