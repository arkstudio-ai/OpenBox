# 三条建议完整展示（2026-09-10）

输入框上方的 Web 和 iOS/Android 建议区统一采用三个等宽、等高的按钮，两侧对齐输入框外边缘。移除编辑图标、横向滚动和文字省略；文字居中自动换行，并平衡多行宽度，避免第二行只剩一个字。发送与填入草稿的语义、提示和点击行为保持原样。生成中的三个流光占位同步改为等宽布局。

Web 同时修正了高度变化引起的滚动竞态：多行建议出现时，滚动事件可能先于 ResizeObserver 到达，原逻辑会把视口变矮误判成用户离开底部并隐藏建议。现在保留视口变化前的底部状态；用户主动上滑阅读历史仍正常隐藏建议。
