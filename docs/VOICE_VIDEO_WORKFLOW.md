# 语音助手与口播视频任务

## 模型与任务创建

- 主助手读取真实配置的任务 AI 和视频模型，结合上下文解释选项。
- 新任务会话创建前完成任务 AI 选择。视频需求先确认是否口播，再选择视频模型。
- 用户明确选择或委托系统决定时沿用，不重复询问。账户默认值本身不视为本次选择。
- 未完成选择只保存问题卡；取消不创建项目、会话或任务。重复回调复用同一任务。
- 口播任务带入已有 `video-production` 技能、所选模型、分辨率和完整需求。
- 意图理解由模型完成；服务端验证配置 ID、归属、版本和提交状态，不匹配中文指令关键词。

## 语音接管任务卡

- 语音可读取完整问题、选项说明、当前任务的稿件与方案，以及卡片草稿中已选的素材。
- 同一次回答提交全部问题和素材 ID；缺少答案时先澄清，不填默认值。
- 用户在卡片上上传的图片可直接被语音识别，无需重新听写文件名。
- 上传草稿不是确认。使用图片、参考生成新图、视频生成费用仍按当前问题和用户决定处理。
- 校验实际发言、卡片版本、任务归属、图片归属及人工接管限制。问题或素材变动后重新读取。
- 语音询问图片内容时读取真实图片；不依据名称编造描述。
- `decision_recorded` 表示回答已提交，不能当作视频已完成。
- Audio 3.1 的附件 JSON 字符串在入口解析为数组；原卡片的问题数量、素材归属和版本校验不变。多道素材题不会猜测图片应分配给哪道题。
- 提交卡片的同一轮语音先等待真实工具回执；同一次发言最多校正一次参数，持续失败停止自动调用，不循环提交。

## 图片通道与技能流程

- Web 和移动端设置提供 **Default / RunningHub**，选择按用户保存。
- RunningHub 具体图片模型由服务端 `image_generation.runninghub_model` 统一配置；密钥留在服务端。
- 技能保留讲稿、素材、完整分镜及费用、实际音频转写和最终交付检查。
- 首尾帧能力按所选视频模型读取。帧率与首尾帧是不同概念；实际时长和 FPS 由成片测量。
- 内置技能资料的执行路径是 `/opt/openbox/skills/<name>/`；自定义主机技能不会因此取得沙箱文件可访问声明。
- 网络错误在尚未产生模型输出时使用已有有限重试预算；已产生输出的请求不自动重放。

## 验收范围

仅执行与本次变更相关的后端测试、问题卡前端测试、TypeScript 检查和移动端改动文件分析，没有执行全量测试。
浏览器验收使用本地 QA 账户，从助手入口创建任务、设置图片来源、回答问题卡、上传图片和播放实际视频。
语音验收通过浏览器麦克风输入测试音频，连接真实 Audio 3.1 服务；不等同于物理麦克风声学测试。

原始日志、测试音频、账号信息和截图保存在本地验收目录，不提交到仓库。
