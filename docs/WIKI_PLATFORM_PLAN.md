# Wiki 平台能力完整实现计划

2026-10-02。用户已授权按计划完整实现。本计划承接 Wiki 阅读改造，范围包括自动概念组织与增量维护、OKF 等格式交换、复杂工作流及网页操作，不能以已有单页编纂功能替代验收。

本计划保留平台移植阶段的已完成验收。后续个人用户要求优先：管理入口已收起，
记忆核验、知识组织和发布改为后台自动执行，用户只需简单编辑。
当前行为与实测见 [面向个人用户的自动知识库](CONSUMER_KNOWLEDGE_IMPLEMENTATION.md)。
末尾的“维护关闭”是当时验收状态，当前 QA 自动维护已开启。

参考源码：`atomicstrata/llm-wiki-compiler@eb18e769db8096c80b81665fb7195e3b29f4cb6b`。
适配 OpenBox 的 SQL 权威数据、身份和项目边界；保留独立编纂核心与宿主服务分层。

## A. 自动概念组织与增量维护

- [x] A1 从当前授权、已确认记忆的原始证据提取概念、别名、类别及有依据的关系，结果按严格契约校验。
- [x] A2 跨来源归并同一概念，维护稳定身份、来源归属和别名；支持人工纠正/合并，避免覆盖不同项目的同名概念。
- [x] A3 按来源/记忆修订、内容 hash、模型与提示版本缓存提取结果；新增、更正、遗忘只重建受影响的概念页。
- [x] A4 后台持久任务具备进度、幂等请求、租约、失败重试、进程恢复及调用预算；资料变化后禁止提交旧结果。
- [x] A5 根据概念归属自动安排页面编纂，进入现有候选审核；从实际证据生成页面和关系，不以模型输出代替发布授权。
- [x] A6 网页提供概念目录、类别/别名、来源与关联、合并/修改、组织预览、运行进度、重试和增量重建操作。
- [x] A7 可明确启停持续维护并设置调用预算；开启后新确认/更正资料可自动触发组织，关闭后停止自动入队。只读浏览不触发模型。
- [x] A8 关系图和页面链接接入概念关系，区分语义关系与共同来源；不把共现展示成已证实的因果关系。

## B. OKF 与格式交换

- [x] B1 兼容上游 OKF 0.1 Markdown bundle：`index.md`、类型化页面、`references/`、`log.md`，保留标准字段及未知生产者扩展。
- [x] B2 导出当前有效页面、引用与来源，以及概念、关系、profile 和工作流的交换元数据；按当前权限重新校验。
- [x] B3 支持 JSON、JSON-LD、GraphML、Marp 和 `llms.txt` 导出，所有格式来自同一授权快照。
- [x] B4 导入提供预览、格式/路径/资源限制校验、引用完整性和冲突报告；支持 ZIP 包并拒绝路径逃逸、符号链接与压缩炸弹。
- [x] B5 外来内容进入待审核，批准前不参与正常召回；外部身份不授予本地访问权限，导入不会覆盖或删除既有页面。
- [x] B6 显式冲突处理、重复导入幂等、版本检查；导入后再导出能保留外部元数据、关系和来源路径，工作流历史不自动变成可执行授权。
- [x] B7 网页可选择格式导出、上传并预览、查看/处理冲突、批准/拒绝候选，下载可用的真实文件。
- [x] B8 用上游格式的独立样例及双向交换验证互操作；不能只用本项目生成器验证本项目读取器。

## C. Profile、生命周期和复杂工作流

- [x] C1 声明式 profile 定义实体类型、字段、关系端点、生命周期状态/转换、工作流阶段及审批门禁，定义校验与执行使用同一契约。
- [x] C2 类型化知识记录的创建、更新、关系和生命周期转换遵守字段与状态规则，关联 Wiki 页面与原始证据。
- [x] C3 多阶段运行持久化输入、定义快照、当前阶段、输出、门禁和审计事件；动作幂等并校验预期版本。
- [x] C4 提交 page/relation/lifecycle/artifact 输出时检查阶段写入范围、必需字段和目标版本；无效输出不能推进阶段。
- [x] C5 人工审批绑定当前阶段及确切输出；替换输出后原审批失效，未完成门禁不能推进。
- [x] C6 支持启动、提交、审核、推进、失败、恢复、取消与完成；定义变化明确阻止旧运行并提供可审查的适配过程。
- [x] C7 实际衔接组织/编纂任务，支持运行重启后恢复观察；不执行来自 profile/导入包的任意代码或 shell。
- [x] C8 网页提供模板/profile 管理、启动表单、阶段状态、输出提交、审批、事件记录和恢复操作；至少一个多阶段流程完成实际浏览器验收。
- [x] C9 生命周期统计包含零计数与不可达状态；工作流记录可导出为可阅读投影和交换历史。
