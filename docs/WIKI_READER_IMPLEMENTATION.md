## 参考版本与设计取舍

参考项目为 `atomicstrata/llm-wiki-compiler`，固定提交
`eb18e769db8096c80b81665fb7195e3b29f4cb6b`（`1.4.0-rc.3`）。
本地参考副本位于 `/Volumes/fanxiang/workspace2/openbox-memory-ref-wiki-20261001`。
这是源码借鉴与宿主适配，没有引入上游运行时，也没有复制其 TypeScript 实现。
原项目的 MIT 声明保留在 `backend/wiki_compiler/UPSTREAM_LICENSE`。

原项目确实有独立浏览器：`llmwiki view` 提供目录、文章、全文搜索、引用、
来源预览、关系图、健康状态及审核队列。阅读布局接近传统 Wiki，内容生成方式则以
“来源 → AI 编纂 → 审核 → 知识页面”为核心。该版本的浏览器只读，编纂和审核通过
CLI/MCP 执行；页面与图数据主要是启动时快照。

OpenBox 沿用现有 SQL 权威数据、用户/workspace/project 权限与后台任务，
把编纂、审核和阅读放进同一网页流程。浏览行为仅查询数据，模型调用由明确确认费用的
编纂、整理或工作流任务触发；持续维护需要单独开启并设置预算。

| 参考入口 | OpenBox 对应实现 | 适配方式 |
| --- | --- | --- |

| `src/viewer/render.ts` | `frontend-v2/src/features/memory/wiki/` | 独立 Wiki 路由、导航、Markdown 文章、目录、来源侧栏；适配窄屏 |

## 已实现的用户流程

- 侧栏“Wiki 知识库”进入 `/app/wiki`；长期记忆管理和 Wiki 检索结果都可打开阅读页。
- 按项目、标题/正文、发布状态浏览目录，分批加载；文章有独立地址 `/app/wiki/:pageId`。
- Markdown 标题、列表、表格、代码块、页内目录和编号引用；同范围且唯一匹配的
  `[[slug|名称]]`/`[[标题]]` 可跳转已加载的有效页面。
- 引用按来源 ID 与真实修订号归并，同一来源的不同原文摘录完整保留。
  点击引用定位依据，可展开全文并返回原始对话。
- 相关文章与关系图只计入实际被引用的有效来源；共同编纂输入不自动等同于共同引用。
- 新建页面先选择明确资料、标题与范围，再确认模型费用；提交后显示任务状态，生成候选而不直接发布。
- 更新页面继承原页面的项目范围与来源选择；更改标题、标识或资料会撤销已勾选的费用确认。
- 待审核页显示候选正文与引用，可批准或拒绝；批准使用不可变候选版本与目标版本校验。
- 相同资料、标题和编纂方式复用既有页面，显示“本次没有调用模型”。
- 导出 Markdown 前重新校验当前权限和来源，导出内容包含版本化来源与原文摘录。
- 来源变更、失去访问权限或被遗忘后，旧正文、搜索片段和来源全文停止提供；过期页面不可导出。

编纂提示与输出格式更新为 `markdown-paragraph-citations-v2`，使提示变更进入编纂签名，
避免旧缓存被当作新格式结果复用。引用标记与段落之间留空行，防止列表末项吞入段落引用。

## 与原项目的差距及规模边界

| 能力 | 当前范围 |
| --- | --- |
| 核心编纂、来源校验、候选审核、发布与失效 | 已适配 OpenBox；继承现有后台任务和可重建索引链路 |
| 人阅读的 Wiki 页面 | 已补齐独立目录、文章、引用、搜索和关联入口 |
| 概念与语义关系图 | 已补充来源约束的概念、别名、类别和关系审核；语义关系与共同来源分开展示；未加入力导向拖拽/缩放 |
| 全库语义查询与图扩展 | Wiki 目录使用有效正文的文本匹配；现有长期记忆召回另走自身检索链路，不把目录搜索称为上游混合检索 |
| 分类、别名、自动发现概念、增量概念页编纂 | 已完成，包含人工修改/合并、持久任务、缓存和可启停的预算维护 |
| 类型、生命周期和工作流门禁 | 已完成本地声明式契约、多阶段执行、审核、定义适配和历史导出；全库 lint 健康仪表盘不在本轮范围 |
| OKF、JSON、JSON-LD、GraphML、Marp、llms.txt | 已完成网页导入/导出及上游源码双向互操作验收；单页 Markdown 导出继续保留 |
| TypeScript SDK、完整 CLI/MCP 和全部上游 profile 扩展 | 未逐一移植；本地为 Python 核心、SQL 宿主和网页流程 |
| 传统 Wiki 的自由编辑、多人协同与完整历史差异查看 | 未实现；当前支持来源驱动的更新和候选审核 |

编纂预算沿用最多 12 条记忆、12 个唯一来源、16,000 个来源字符。
目录每次最多检查 200 条记录，可能返回空批次及继续加载游标；默认返回 40 个匹配结果。
图最多绘制当前已加载的 40 个页面，相关文章与 Wiki 链接也受已加载目录限制。
审核列表沿用最近 100 条候选并明确提示上限。当前没有大规模全库性能验收，
不以未经定义的百分比宣称与上游功能等价。
