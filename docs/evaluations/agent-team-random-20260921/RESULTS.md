## 本次发现并修复的问题

1. **自动追加成员被错误拒绝。** 追加成员曾重新编译一个采用全局默认模型的
   协调者。当默认模型不在当前团队授权中，即使新成员明确指定允许的 Qwen，
   仍返回 `MODEL_NOT_ALLOWED`。现只编译新成员，沿用已确认授权；已保存
   Agent、临时成员、模型覆盖、幂等重放和越权拒绝均有回归覆盖。
2. **忙碌成员收到消息后被误标成排队。** 固定团队的 reviewer 在同一个活跃
   Driver 中生成回复时，收到同伴消息后由 running 退回 queued。修复保留
   活跃执行状态，等待中的成员仍正常入队。修复前两个忙碌场景失败、两个等待
   场景通过；修复后相关 48 项测试通过，消息只投递一次，Driver 代次不变。

第一项修复在抽样前完成；第二项由最后一条实测发现，在抽样结束后完成。
