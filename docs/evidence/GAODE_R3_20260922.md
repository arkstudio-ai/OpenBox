## 新回归：重新打开同一会话后历史空白

复现：

1. 打开上述会话，等待模型回复完毕；页面有两条消息。
2. 不改变已有会话 ID，再点一次“打开”。
3. 会话状态正常显示 idle/low，但消息区为空，DOM 中 `.msg` 数量从 2 变 0。
4. 等待网络请求完成后仍为空；直接 GET 同一会话 messages 返回两条、finish=stop。

对应 GET session request_id：`req_01M34KPN0ZSBF0CD87HC1FM80Z`。

原因：`docs/external/gaode-console.html` 的 `useSession()` 清空 messages.innerHTML 和 dataset.html，但新版 render() 使用 dataset.sig。旧 sig 未重置；相同历史算出的 sig 相同，render() 提前 return，使刚清空的消息区无法恢复。

建议：useSession() 清空 messages 时同步删除/reset dataset.sig，并回归“同一会话重复打开”“切换后再打开”“打开仍在处理的会话”。本轮只验收并记录，没有改产品代码。
